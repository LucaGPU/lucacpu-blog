Initial Research I did

Since switching to Linux, I have been fascinated by the very prospect of GNU/Linux phones, phones free of Apple and Googles direct control. Now, getting into Linux mobile is stupidly hard. Firstly, you need a compatible device, despite being Linux based Android phones don't always work. In fact, the ones that do work are in the minority. So, what phones work and distros even exist?

The answer is the same for both. You see, Distributions and hardware support are linked. What works on Ubuntu touch may not work on Mobian or PostmarketOS for example. So let’s simplify this explanation by focussing on the distros that exist and separating them into two categories.

Hallium and Mainline

Hallium distros use the Android kernel alongside all the hardware drivers built for it. They then add the normal Linux software stack on top. Mainline distros use the mainline Linux kernel as used by a normal Linux distro such as Debian or Fedora.

What does this mean for hardware support? Well, Hallium distros have a larger device support with almost all hardware features working, however mainline distros don't. So why does a mainline distro even exist? well, Hallium being great, is not quite the golden cure. Hallium fundamentally as I understand it is a hack, it allows near native hardware compatibility, however the rest of the Linux desktop stack was not designed for the Android kernel and so instability is introduced.

Hallium Vs Mainline

Ubuntu Touch has a great solution for this, create a tightly integrated new Linux mobile stack built with the Android kernel in mind. This fixes the stability issue but now the system is more locked down due to the tight integration. While it’s more open than say iOS and Android, not being as open as desktop Linux means you have much less available applications.

A good example is the lack of Flatpak/Flathub support. 90% of all Linux applications are on Flathub and not having any support means you loose out on that massive app library. Another issue is because this is a new OS stack, most programs wouldn’t work anyway due to incompatible libraries, missing packages etc etc.

If you don’t care all that much about stability and care more about control, you can use the normal Desktop stack on top of Hallium and use a mainline mobile environment such as Phosh or Plasma Mobile. A distro that does this is Droidian (I have yet to find another like it).

Now I have yet to explain mainline distros. Mainline distros are basically just a Linux distro using the mainline kernel. Examples include NuraOS (Formerly PostmarketOS), Mobian and PureOS. The only devices with perfect support for these are the Pinephone and Librem5.
