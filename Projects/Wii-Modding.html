Intro

Since I was about 12 I have soft modded old consoles to either breathe new life into them or to learn more about the hardware. The Wii was my first system I modded. I used the letterbomb exploit which took advantage of a system vulnerbility found in the systems Mail menu.

On the modded Wii, I installed Riiconnect24 to bring back the Wii's 24/7 Online service and quite recklessly messed with system files. This did result in a few bricks, Bricks in this context mean the system would not be able to boot into the OS. From this I learned how to recover from system bricks and in the process, how the Wii System Software worked.

My understanding of the system software

The Wii system software is split into two seperate WAD files. (not the Doom kind lol) These are IOS (Internal Opperating System) & Wii Menu. Technically the settings menu is also seperate but only in the fact that its configs are largely seperate from the main system files.

The Wii system software is also notoriously horrible at error handling. The most common brick known as a bannerbrick is where a malformed banner causes the Wii to crash upon boot. Funily enough, this can be caused by the resolution of the banner to be not what the Wii expects and so it brings the system down with it.
